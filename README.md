# Al-Burhan: The Mawlid Analysis

A comprehensive juridical analysis of the Mawlid (celebration of the Prophet's birth) based on Ahlussunnah wal Jama'ah principles, examining the Ashari and Maturidi schools' perspectives on the legal classification of Bid'ah.

## About This Project

This web application presents a structured analysis of the Mawlid celebration through the lens of Islamic jurisprudence, specifically focusing on:

- The Ashari school's position on Bid'ah classification
- The Maturidi school's jurisprudential framework
- Legal evidence and scholarly opinions
- A comprehensive comparison of the two approaches

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn package manager

### Installation

1. Clone the repository:
```sh
git clone <your-repository-url>
cd <project-directory>
```

2. Install dependencies:
```sh
npm install
```

3. Start the development server:
```sh
npm run dev
```

The application will be available at `http://localhost:8080`

### Building for Production

To create a production build:

```sh
npm run build
```

The built files will be in the `dist` directory.

### Preview Production Build

To preview the production build locally:

```sh
npm run preview
```
